# Telegram Admin Manager Updates

Автоматический канал обновлений Telegram Admin Manager.

Текущая версия: **4.2.9**

Релизы публикуются через постоянный GitHub Actions workflow. Пайплайн восстанавливает предыдущий проверенный release, накладывает изменения новой версии, компилирует код, запускает unit-тесты, собирает ZIP, создаёт GitHub Release и только после успешной публикации обновляет `update.json`.

Этот репозиторий используется приложением для проверки `update.json` и скачивания release-пакетов.

> В репозиторий не загружаются `data`, `.session`, `state.db`, API Hash или другие пользовательские данные.
